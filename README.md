
# Jogo de Terror

## Sobre o Projeto

Este projeto é um jogo de terror inspirado na ideia de *Five Nights at Freddy's (FNAF)*, com uma proposta de gameplay assimétrica para dois jogadores.

Cada jogador terá um papel diferente: um será responsável por controlar as criaturas que ameaçam o local, enquanto o outro assumirá o papel de um segurança que precisa sobreviver durante a noite.

A proposta é criar uma experiência de tensão, estratégia e suspense, na qual cada jogador terá objetivos e ferramentas diferentes para vencer.

## Jogabilidade

O jogo será dividido em dois papéis principais:

### Jogador 1 — Criaturas

O jogador responsável pelas criaturas terá como objetivo perseguir e capturar o segurança.

Suas possíveis mecânicas incluem:
- Controlar os movimentos das criaturas.
- Explorar o ambiente para encontrar oportunidades de ataque.
- Utilizar estratégias para surpreender o segurança.
- Aproveitar os pontos cegos e as limitações dos sistemas de vigilância.

### Jogador 2 — Segurança

O jogador responsável pela segurança deverá sobreviver aos ataques das criaturas até cumprir seu objetivo.

Suas possíveis mecânicas incluem:
- Monitorar câmeras de segurança.
- Observar os movimentos das criaturas.
- Gerenciar recursos limitados, como energia.
- Utilizar portas, luzes ou outros mecanismos defensivos.
- Sobreviver até o fim do turno.

## Objetivo do Jogo

Cada jogador terá uma condição de vitória diferente:

- **Criaturas:** encontrar e capturar o segurança antes que o tempo acabe.
- **Segurança:** sobreviver até o final do turno sem ser capturado.

O equilíbrio entre os dois lados será fundamental para garantir partidas desafiadoras e divertidas.

## Diferencial

O principal diferencial do projeto é permitir que um jogador controle diretamente as ameaças, em vez de enfrentar apenas inimigos controlados pela inteligência artificial.

Isso cria uma disputa entre dois jogadores, na qual as decisões de um influenciam diretamente as estratégias do outro.
